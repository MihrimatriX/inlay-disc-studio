# 0002 — FluentAssertions pinned to 7.2.x

**Status:** accepted (M0)

FluentAssertions 8+ is under the Xceed commercial license. 7.2.x is the last Apache-2.0 line and covers
everything the tests need. If 7.x stops working on a future SDK, switch to AwesomeAssertions (Apache-2.0
fork, same API, different namespace) rather than buying a license.
